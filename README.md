# 西华大学教学评价助手

一个用于西华大学正方教务系统的浏览器用户脚本，用来批量填写学生教学评价。

> 默认为“仅保存”模式，不会直接提交评价。请在使用后核对每门课程的选项和评语。

## 功能

- 识别当前列表中状态为“未评”或“未评完”的课程。
- 逐门加载评价表单并选择评价项。
- 第一题优先选择 80 分（“比较同意”）。
- 其余题目优先选择 100 分（“非常同意”）。
- 自动填写预设评语。
- 保存成功后关闭提示框，继续处理下一门课程。
- 当本页没有待评课程时，自动尝试翻到下一页。
- 在页面右上角显示开始、停止和运行状态。

## 适用范围

脚本仅在以下页面运行：

```text
https://jwc.xhu.edu.cn/xspjgl/xspj_cxXspjIndex.html*
```

脚本依赖该页面现有的 jQuery、jqGrid 和 DOM 结构。如果教务系统更换域名、页面路径或前端结构，脚本可能需要更新后才能继续使用。

## 安装

1. 在浏览器中安装 ScriptCat、Tampermonkey 或其他兼容的用户脚本管理器。
2. 通过 [ScriptCat 脚本页面](https://scriptcat.org/zh-CN/script-show-page/5165) 安装
3. 登录西华大学教务系统，进入学生评教页面。

## 使用

1. 等待评教页面加载完成。
2. 确认右上角出现“西华大学评教助手”面板。
3. 点击“开始”，脚本将从列表中第一门待评课程开始处理。
4. 观察面板中的课程、教师和处理进度。
5. 处理完成后，手动检查已保存的评价，确认无误后再按学校要求提交。

点击“停止”会设置停止标记。如果脚本正在填写题目，它会在下一次检查到该标记时退出；已经选中的内容不会被撤销。

## 配置

如需调整默认行为，请编辑脚本顶部的 `CONFIG`：

| 配置项 | 默认值 | 用途 |
| --- | --- | --- |
| `actionType` | `'save'` | `'save'` 仅保存；`'submit'` 保存并提交 |
| `comment` | `老师讲课认真负责，内容充实，收获很多，希望继续保持。` | 自动填写的评语；设为空字符串可禁用 |
| `delayBeforeSelectRow` | `[200, 500]` | 选择课程前的随机延时 |
| `delayAfterFormLoaded` | `[500, 1000]` | 评价表单加载后的随机延时 |
| `delayPerQuestion` | `[20, 80]` | 每道题之间的随机延时 |
| `delayBeforeSave` | `[80, 300]` | 保存或提交前的随机延时 |
| `delayAfterSave` | `[200, 500]` | 保存完成后的随机延时 |
| `delayAfterNextPage` | `[1000, 2000]` | 翻页后的随机延时 |
| `modalAppearTimeout` | `6000` | 等待结果弹窗的最长时间 |
| `delayAfterModalClose` | `[200, 500]` | 关闭结果弹窗后的随机延时 |
| `rowLoadTimeout` | `10000` | 等待评价表单加载的最长时间 |

延时数组的单位均为毫秒，脚本会在最小值和最大值之间随机等待。

> 将 `actionType` 设为 `'submit'` 后，脚本会尝试确认提示并直接提交每门课程的评价。提交可能无法撤销，请先在 `'save'` 模式下核对效果。

## 异常处理

- 没有出现脚本面板：确认页面地址与上述适用路径一致，并确认用户脚本已启用。
- 提示“页面未检测到 jQuery”：刷新页面并等待页面完整加载。
- 课程加载超时：请检查网络和课程表单，必要时停止脚本后手动处理。
- 未检测到成功弹窗：可能是保存失败或页面结构已变化，请立即检查当前评价状态。

## 已知限制

- 脚本按评价选项的 `data-dyf` 分值匹配 80 分和 100 分；如未找到，会回退到指定顺序的选项。
- 翻页和弹窗处理依赖固定的页面元素与等待时间，网络较慢时可能失败。
- 课程加载超时后，当前实现可能再次尝试同一门未评课程。
- 运行期间请勿重复点击“开始”，否则可能同时启动多个处理流程。
